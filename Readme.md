## The Goodness Kitchen — demo site (v2)

Static concept site: HTML + GSAP + three.js (both via CDN). No build step.

- `index.html` — the page (hero, 3D box, story, process, health, menu, order CTA)
- `box3d.js` — realistic 3D hexagonal kraft box that opens and spins on scroll
- `img/` — AI-generated placeholder photos (Canva)

Run locally with any static server (e.g. `npx serve .`), or deploy the folder as-is to Vercel (framework preset: Other, no build command).
